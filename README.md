# Blok Ustası

Türkçe arayüzlü, çevrimdışı oynanabilen blok yerleştirme bulmacası. Orijinal oyun adı ve görselleri kullanılmaz.

## Özellikler
- 10×10 oyun tahtası
- Üç blok seçeneği; seçip tahtada dokunarak veya sürükleyerek yerleştirme
- Dolu satır ve sütunları temizleme
- Puan, kalıcı rekor ve kombo sistemi
- Ses efektleri, desteklenen cihazlarda titreşim
- Türkçe koyu arayüz; ağ izni gerektirmez

## Android APK derleme
Android SDK 36 ve Java 17 yüklü Termux ortamında proje klasöründe şunu çalıştır:

```bash
bash build-apk.sh
```

Derleme başarılı olursa APK şu konuma kopyalanır:
`~/storage/downloads/BlokUstasi.apk`

Paket kimliği: `com.blokustasi.game`
